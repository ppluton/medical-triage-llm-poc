# Politique de sécurité

## Périmètre

Ce dépôt est un Proof of Concept éducatif. Il n'est pas autorisé pour un usage médical, hospitalier ou patient réel.

## Signaler un problème

Ne publiez pas de secret, de donnée personnelle ou de donnée de santé dans une issue publique. Utilisez la fonction privée de signalement de vulnérabilité GitHub du dépôt lorsqu'elle est disponible.

Pour un défaut non sensible, ouvrez une issue en indiquant la version, le scénario synthétique minimal et le comportement observé.

## Données interdites

Les contributions contenant des dossiers patients, exports hospitaliers, identifiants directs, clés API, variables d'environnement, checkpoints ou logs sensibles seront refusées.

## Garanties

Les contrôles d'anonymisation, de schéma et de sûreté présents dans le dépôt sont des preuves techniques limitées. Ils ne constituent ni une certification RGPD, ni une validation clinique, ni une homologation de sécurité.
