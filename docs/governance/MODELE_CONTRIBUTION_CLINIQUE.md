# Modèle de contribution clinique — scénarios de triage

Utiliser uniquement des scénarios synthétiques ou anonymisés et approuvés.

```text
Identifiant scénario :
Langue : fr / en
Contexte symptomatique synthétique :
Informations manquantes / contradictoires :
Niveau attendu : maximum / moderate / deferred / non défini
Comportement attendu :
Signaux d'alerte :
Réponse chosen (DPO, si applicable) :
Réponse rejected (DPO, si applicable) :
Justification / protocole de référence :
Version du protocole :
Réviseur clinique :
Date et statut : proposed / approved / rejected
```

Une contribution `proposed` peut servir à discuter le format, jamais à conclure une performance clinique. Seules les contributions `approved` peuvent constituer une référence de triage.
