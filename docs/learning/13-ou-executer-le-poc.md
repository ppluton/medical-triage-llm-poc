# Étape 13 — Où exécuter le POC ?

Le SSD sert à stocker localement les modèles et résultats lourds sans remplir le disque interne. Hugging Face fournit le catalogue de modèles, une démo possible et des endpoints managés. Un GPU cloud devient utile pour LoRA/DPO quand le Mac ne suffit plus. Chaque surface a des coûts, des limites de stockage et des règles de confidentialité différentes.
