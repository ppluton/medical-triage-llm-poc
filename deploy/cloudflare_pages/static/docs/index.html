Le contrat de l’API FastAPI

Ce schéma est généré par l’application FastAPI et vérifié dans les tests du dépôt. Swagger permet de lire les entrées, les sorties et les erreurs de validation.

En ligne : navigateur → proxy Cloudflare (contrôle d’accès) → FastAPI sur Modal → modèle vLLM → garde-fous → réponse JSON.

Les appels se lancent depuis le formulaire sécurisé de démonstration. Ouvrez ensuite « Montrer l’appel API FastAPI » pour voir la requête et la réponse réelles, sans afficher le jeton.
